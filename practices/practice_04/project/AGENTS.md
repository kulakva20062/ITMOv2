# AGENTS.md — проект Практики 4

Проект: `experiment.py` — контролируемый запуск локальной модели через Ollama
(`/api/chat`), только стандартная библиотека Python 3.10+.

## Источники

Перед изменением кода прочитай `docs/style-guide.md`.

- Контракт: `docs/requirements.md` (фичи A и B, коды выхода, сообщения).
- Пример теста в стиле проекта: `demo/test_service.py` (`unittest`, без фреймворков).
- Тесты `experiment.py`: `tests/test_experiment.py` (`unittest.mock.patch`
  на `urllib.request.urlopen`, реальная Ollama в тестах не нужна).

## Команда проверки

```sh
sh scripts/check.sh
```

Запускать из каталога `project/`. Работа считается сделанной, только если
команда завершилась с кодом 0.

## Ограничения

- Не менять контракт `docs/requirements.md` и runner `scripts/check.sh`
  без поручения студента. Не ослаблять проверки ради зелёного результата.
- Только стандартная библиотека Python (`unittest`, `unittest.mock`, `urllib`).
  Сторонние пакеты не ставить.
- Не трогать `practices/practice_03` и другие практики — это сданные артефакты.
- Поведение успешного запуска и формат JSON-записи не менять.
- Не коммитить и не делать push: это решает студент.
