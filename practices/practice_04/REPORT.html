В. Свой MCP-сервер ollama_info_server.py

mcp/ollama_info_server.py — stdio, JSON-RPC 2.0 только на stdlib: initialize, tools/list, tools/call, ping; уведомления игнорируются. Tool ollama_model_info(model) берёт из /api/show семейство (details.family), размер (details.parameter_size), квантизацию (details.quantization_level) и длину контекста (model_info["<arch>.context_length"]). На пустое имя, отсутствующую модель или недоступную Ollama сервер возвращает результат с isError: true и не падает. Если arguments не объект, сервер тоже отвечает isError: true. На неизвестный tool он отвечает JSON-RPC-ошибкой −32602, на неизвестный метод — −32601, на не-объект — −32600, а любое неожиданное исключение превращает в −32603, не завершая процесс. Регистрация: claude mcp add --scope project ollama-info -- python3 mcp/ollama_info_server.py, запись появилась в .mcp.json, сервер добавлен в enabledMcpjsonServers.

Реальный вызов: claude -p "Вызови MCP-инструмент ollama_model_info трижды ..." --allowedTools "mcp__ollama-info__ollama_model_info"

MCP [{'name': 'context7', 'status': 'connected'}, {'name': 'ollama-info', 'status': 'connected'}]

  RESULT {"model": "qwen3.8:27b", "family": "qwen35", "parameter_size": "27.3B", "quantization_level": "Q4_K_M", "context_length": 262144}

Польза tool: он показывает, что qwen3.8:27b поддерживает контекст 262144 токена, а проект запускает её с num_ctx 4096.
