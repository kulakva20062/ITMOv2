# Proposal

## Why

Сейчас выйти из суженного или пустого результата можно только вручную: вернуть каждый из двух селектов в «любой» по отдельности. В пустом результате посетитель видит подсказку, но не видит действия — ближайший выход из тупика не нажимается одним движением. Кнопка «Сбросить фильтр» даёт этот выход и делает состояние фильтра по умолчанию достижимым за один клик.

## What Changes

- В блок фильтра `#fleet` добавляется кнопка «Сбросить фильтр» (`<button type="button">`, без `<input>` — `<input>` выше `#calculator` сломал бы разбор поля срока в тестах).
- Нажатие кнопки возвращает оба селекта в значение «любой», перерисовывает реестр со всеми машинами и обновляет счётчик до «Показано 8 из 8».
- Кнопка `disabled`, когда фильтр уже в состоянии по умолчанию (оба селекта в «любой»): при открытии страницы и сразу после сброса. Становится активной, как только выбран хотя бы один непустой критерий.
- В пустом результате рядом с существующей строкой `EMPTY_MESSAGE` появляется вторая строка-подсказка, предлагающая нажать «Сбросить фильтр». Текст `EMPTY_MESSAGE` не меняется — он зафиксирован в `docs/requirements.md` и в `tests/filter.test.js`; подсказка приходит отдельной экспортируемой константой.
- В `src/filter.js` добавляется чистая функция-предикат состояния по умолчанию (`isFilterDefault`) и константа текста подсказки — обе покрываются тестами.
- Сохраняется без изменений поведение из `openspec/specs/fleet-filtering`: сброс не трогает отметку выбранной машины за пределами перерисовки реестра, не пишет в `#fleet-status`, список машин в калькуляторе остаётся полным.

Вне объёма: хранение состояния фильтра в URL или `localStorage`, новые критерии отбора (цена, число мест, поиск по модели), сортировка реестра.

## Capabilities

### New Capabilities

Новых capability нет: сброс — часть поведения уже описанного отбора автопарка и живёт в том же `src/filter.js` и том же блоке `#fleet`.

### Modified Capabilities

- `fleet-filtering`: добавляются требования к сбросу фильтра одним действием (возврат обоих признаков в «любой», полный реестр, счётчик «Показано 8 из 8»), к недоступности кнопки в состоянии по умолчанию и к подсказке со сбросом в пустом результате. Уточняется публичный контракт `src/filter.js` — в нём появляются предикат состояния по умолчанию и текст подсказки. Требование «Пустой результат отбора» дополняется второй строкой; его обязательный текст `EMPTY_MESSAGE` остаётся прежним.

## Impact

- `index.html` — кнопка в блоке `.fleet-filter` секции `#fleet`.
- `styles.css` — стили кнопки и её состояния `disabled` на существующих токенах (`--ink`, `--ink-2`, `--rule`); новых цветов нет, место под кнопку в сетке `.fleet-filter`.
- `src/filter.js` — новая чистая функция `isFilterDefault` и константа подсказки пустого результата.
- `src/main.js` — обработчик нажатия, пересчёт состояния `disabled` при каждой перерисовке реестра, вторая строка в блоке пустого результата.
- `tests/filter.test.js`, `tests/index.test.js` — новые тесты на предикат, текст подсказки и разметку кнопки. Существующие проверки, включая «в секции автопарка нет ни одного `input`» и точный текст `EMPTY_MESSAGE`, остаются в силе.
- `docs/requirements.md` — конфликт контракта: строка 78 («Вне объёма фичи C») прямо называет кнопку сброса фильтра вне объёма. Правка документа в объём этого change не входит и требует отдельного поручения студента; до неё приёмка по `docs/requirements.md` будет считать кнопку лишней.
