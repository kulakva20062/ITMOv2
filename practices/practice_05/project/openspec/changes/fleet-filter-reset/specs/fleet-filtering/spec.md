# Spec Delta

## ADDED Requirements

### Requirement: Сброс фильтра одним действием

Блок фильтра SHALL предлагать действие «Сбросить фильтр», которое возвращает фильтр в состояние по умолчанию: оба признака — класс и коробка — принимают значение «любой». Действие выполняется одним нажатием, без промежуточного подтверждения.

#### Scenario: Сброс из суженного результата

- **WHEN** посетитель выбрал класс «внедорожник» и коробку «механика», а затем нажал «Сбросить фильтр»
- **THEN** селект класса стоит в значении «Любой класс»
- **AND** селект коробки стоит в значении «Любая коробка»
- **AND** в реестре показаны все машины автопарка в исходном порядке
- **AND** счётчик показывает «Показано 8 из 8»

#### Scenario: Сброс из пустого результата

- **WHEN** посетитель в пустом результате нажал «Сбросить фильтр»
- **THEN** строка про отсутствие машин и подсказка про сброс убраны
- **AND** шапка реестра показана снова
- **AND** в реестре показаны все машины автопарка

#### Scenario: Сброс при одном выбранном признаке

- **WHEN** выбрана только коробка, класс остаётся «любой», и посетитель нажал «Сбросить фильтр»
- **THEN** селект коробки вернулся в «Любая коробка»
- **AND** в реестре показаны все машины автопарка

### Requirement: Сброс недоступен в состоянии по умолчанию

Действие «Сбросить фильтр» MUST быть недоступно (`disabled`), когда фильтр уже в состоянии по умолчанию — оба признака в значении «любой», — и доступно, как только выбран хотя бы один признак. Недоступность пересчитывается при каждой перерисовке реестра, а не только при смене селекта.

#### Scenario: Открытие страницы

- **WHEN** посетитель открыл страницу и не трогал фильтр
- **THEN** действие «Сбросить фильтр» недоступно

#### Scenario: Выбран один признак

- **WHEN** посетитель выбрал класс «внедорожник»
- **THEN** действие «Сбросить фильтр» доступно

#### Scenario: Сразу после сброса

- **WHEN** посетитель нажал «Сбросить фильтр» из суженного результата
- **THEN** фильтр в состоянии по умолчанию
- **AND** действие «Сбросить фильтр» снова недоступно

#### Scenario: Возврат признаков в «любой» вручную

- **WHEN** посетитель вернул оба селекта в «любой» руками, не нажимая сброс
- **THEN** действие «Сбросить фильтр» недоступно, потому что фильтр в состоянии по умолчанию

### Requirement: Сброс не затрагивает выбор машины

Сброс фильтра MUST касаться только состояния фильтра и реестра: выбранная машина остаётся выбранной, сообщение о выборе не меняется, список машин в калькуляторе остаётся полным.

#### Scenario: Отметка выбранной машины после сброса

- **WHEN** посетитель выбрал машину, сузил фильтр так, что она перестала показываться, и нажал «Сбросить фильтр»
- **THEN** машина снова показана в реестре с отметкой выбранной
- **AND** она по-прежнему выбрана в списке калькулятора

#### Scenario: Сообщение о выборе переживает сброс

- **WHEN** посетитель нажал «Рассчитать» у машины, а затем нажал «Сбросить фильтр»
- **THEN** сообщение о выбранной машине осталось прежним и в своей области
- **AND** счётчик обновился в своей области

### Requirement: Фильтр остаётся без полей ввода

Блок фильтра MUST состоять только из элементов `<select>` и `<button>`: ни одного `<input>` в секции `#fleet`. Поле срока калькулятора разбирается в тестах от первого `<input>` документа, и любой `<input>` выше `#calculator` подменил бы этот разбор.

#### Scenario: Разметка блока фильтра

- **WHEN** в секции `#fleet` появляется действие «Сбросить фильтр»
- **THEN** оно сделано элементом `<button>` с явным `type="button"`
- **AND** в секции `#fleet` нет ни одного `<input>`

## MODIFIED Requirements

### Requirement: Пустой результат отбора

Когда под выбранные условия не подходит ни одна машина, автопарк MUST показывать строку «Под эти условия машин нет — выберите «Любой класс» или «Любая коробка»», MUST рядом с ней показывать подсказку, предлагающую нажать «Сбросить фильтр», и MUST скрывать шапку реестра, чтобы подписи колонок не висели над пустотой.

#### Scenario: Сочетание без машин

- **WHEN** посетитель выбирает класс «бизнес» и коробку «механика», под которые машин нет
- **THEN** показана строка «Под эти условия машин нет — выберите «Любой класс» или «Любая коробка»»
- **AND** рядом показана подсказка, называющая действие «Сбросить фильтр»
- **AND** шапка реестра с подписями колонок скрыта
- **AND** ни одной строки машины в реестре нет

#### Scenario: Выход из пустого результата

- **WHEN** посетитель из пустого результата возвращает коробку в «Любая коробка»
- **THEN** строка про отсутствие машин и подсказка про сброс убраны
- **AND** шапка реестра показана снова
- **AND** в реестре показаны машины класса «бизнес»

### Requirement: Неизвестное значение фильтра отвергается

Отбор MUST бросать `RangeError` с понятным текстом, называющим недопустимое значение, когда ему передано значение класса или коробки, которого нет в данных автопарка. Публичный контракт отбора — чистые функции в `src/filter.js`: `filterCars(cars, { carClass, gearbox })` для отбора, `filterOptionsHtml` для опций селектов, `countLabel` для текста счётчика, `isFilterDefault({ carClass, gearbox })` для признака состояния по умолчанию, `EMPTY_MESSAGE` для строки пустого результата и `EMPTY_RESET_HINT` для подсказки про сброс.

#### Scenario: Неизвестный класс

- **WHEN** отбор вызван со значением класса, отсутствующим в списке классов автопарка
- **THEN** брошен `RangeError`
- **AND** текст ошибки называет недопустимое значение и говорит, что исправить

#### Scenario: Неизвестная коробка

- **WHEN** отбор вызван со значением коробки, отсутствующим в списке коробок автопарка
- **THEN** брошен `RangeError`
- **AND** текст ошибки называет недопустимое значение и говорит, что исправить

#### Scenario: Признак состояния по умолчанию — чистая функция

- **WHEN** признаку состояния по умолчанию переданы оба значения «любой», либо отсутствующие значения
- **THEN** он отвечает, что фильтр в состоянии по умолчанию

#### Scenario: Признак состояния по умолчанию при выбранном признаке

- **WHEN** признаку состояния по умолчанию передано конкретное значение класса или коробки
- **THEN** он отвечает, что фильтр не в состоянии по умолчанию
