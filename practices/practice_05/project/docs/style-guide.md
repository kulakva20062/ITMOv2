# Style guide AutoDrive

Перед изменением вёрстки прочитай этот файл. Пример, где правила уже выполнены: секция `#fleet` в `index.html` и `styles.css`.

## Визуальный язык
Лендинг оформлен как приёмо-сдаточный лист осмотра: бумага, волосяные линии, подписи полей в левой рейке. Новые блоки (калькулятор и др.) продолжают этот язык, а не вводят карточки с тенями.

## Токены — только через переменные `:root`
| токен | значение | где |
|---|---|---|
| `--paper` | `#EDF0EE` | фон |
| `--ink` | `#1B2A3A` | основной текст |
| `--ink-2` | `#5A6871` | подписи полей, вторичный текст |
| `--rule` | `#C3CAC7` | линии |
| `--signal` | `#F0B323` | главная кнопка, выбранное состояние, фокус |
| `--stamp` | `#B4342A` | только ошибки ввода |

Новых цветов не добавляй. Пары текст/фон должны проходить WCAG AA (4.5:1 для обычного текста).
Контраст к `--paper`: `--ink` 12.72:1, `--ink-2` 5.01:1, `--stamp` 5.28:1.

## Правила
1. Без теней и градиентов; `border-radius` 0 у полей и строк, 2px у кнопок.
2. Шрифты — только локальные стеки из `styles.css`; цифры в ценах — `font-variant-numeric: tabular-nums`.
3. Суммы выводятся только через `formatPrice` из `src/format.js`.
4. Ошибка ввода — текст цветом `--stamp` рядом с полем, с `role="alert"`; не извиняемся, говорим, что исправить.
5. Анимация — одна на странице (заливка кузова в hero); всё новое без анимации, `prefers-reduced-motion` уважаем.
6. Поведение проверяем через публичный интерфейс: экспортируемые функции и разметку `index.html`. Не ослабляй runner и тесты ради зелёного результата.
