# AutoDrive — лендинг проката автомобилей

Стек: чистые HTML, CSS и JavaScript (ES-модули), без фреймворков, сборщиков и npm-зависимостей.
Тесты: встроенный раннер Node 24 (`node --test`).

## Перед работой прочитай
- Требования и фичи A/B: `docs/requirements.md`.
- Визуальный стиль: `docs/style-guide.md` (если файл есть — перед любой правкой вёрстки).
- Пример теста: `tests/format.test.js`.

## Проверка
`sh scripts/check.sh` — должна проходить после каждой правки.

## Правила
- Только вымышленные данные: никаких реальных адресов, телефонов, e-mail и брендов прокатов. Заглушки: `+7 000 000-00-00`, `hello@example.com`.
- Не подключай внешние CDN, шрифты и картинки из сети. Изображения — CSS или inline SVG.
- Логику расчётов держи в `src/` как чистые функции и покрывай тестами.
- Не меняй контракт в `docs/requirements.md`, `scripts/check.sh` и существующие тесты ради зелёного результата без поручения.
- Не делай commit — его делает студент после приёмки.
